# **App Name**: Quran Explorer

## Core Features:

- Surah Selection and Details: Display a searchable list of Surahs with details like verse count and transliteration.
- Random Verse Generator: Generate and display a random verse from the selected Surah with translation and source information.
- Verse Navigation: Enable navigation to the previous and next verses within the selected Surah, displaying previous verses chronologically.

## Style Guidelines:

- Primary color: A calming blue (#4285F4) to represent serenity and spirituality.
- Secondary color: A light grey (#EEEEEE) for backgrounds to ensure readability.
- Accent: A warm gold (#FFC107) to highlight important elements and navigation.
- Clean and readable font for verse text and translations.
- Clear and structured layout with Surah details on top, followed by the verse and navigation controls.
- Simple, intuitive icons for navigation (previous, next) and actions (e.g., refresh for a new random verse).

## Original User Request:
Title: Islamic Quran Application with Random Verse Generator and Surah Selector

Description:

Build an ReactJS interactive Quran application where users can:

Select Surahs: Users can choose from a list of Surahs from the Quran to generate random verses.

Generate Random Verse: When a Surah is selected, the user can generate a random verse from it. This verse will be displayed along with its translation and the verse’s source information.

Navigate Between Verses:

The app should allow the user to navigate between the generated verse, previous verses, and next verses within the same Surah.

Buttons should be available for previous and next verses.

Display Previous Verses: As the user navigates through the verses, previous verses should be displayed above the generated verse in chronological order (not reversed).

Display Surah Details: Each Surah should have its own details such as the number of verses, transliteration, and more.
